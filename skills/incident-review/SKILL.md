# Incident Review Skill

Use this skill for source failures, duplicated content, bad summaries, missed deletions, privacy issues, or release regressions.

## Workflow

1. Read `AGENTS.md`.
2. Write a concise timeline.
3. Identify user impact.
4. Identify detection gap and prevention gap.
5. Separate contributing factors from blame.
6. Create follow-up tasks with owners and due dates.

## Required Report

- Incident summary
- Timeline
- User impact
- Root and contributing factors
- What worked
- What failed
- Follow-up actions
- Prevention checks

## Guardrails

- Keep the review blameless.
- Do not hide uncertainty.
- Do not close the incident without owner-assigned follow-ups.
