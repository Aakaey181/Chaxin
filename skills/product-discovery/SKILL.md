# Product Discovery Skill

Use this skill to turn fuzzy product ideas into Zhuixun user stories, assumptions, metrics, and non-goals.

## Workflow

1. Read `AGENTS.md`.
2. Read `docs/product/PRD-v0.1.md` and `docs/product/backlog.md`.
3. Identify the target user, job to be done, and smallest validation path.
4. Write user stories with acceptance criteria.
5. Separate facts, assumptions, risks, and open questions.
6. Update the not-doing list when scope grows.

## Output Format

- User stories
- Acceptance criteria
- Metrics
- Assumptions
- Risks
- Not-doing list

## Guardrails

- Do not add implementation details unless needed for acceptance.
- Do not expand V0.1 without naming tradeoffs.
