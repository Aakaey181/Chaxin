# Zhuixun

Zhuixun V0.1 is a beta product for following people instead of platforms. The foundation in this repository sets up the Codex operating model, role files, reusable skills, product documents, architecture decisions, and initial project skeleton.

## Start With Codex

Use this prompt for the first task:

```text
Please read AGENTS.md first, then follow agents/architect.md and skills/release-gate/SKILL.md.
Current goal: check whether Week 0 foundation is complete, fill missing files, and only do A-D. Do not implement business functionality.
Report changed files, test results, unresolved risks, and next steps.
```

## Week 0 Scope

- A. Create or complete `AGENTS.md`.
- B. Create `agents/*.md` and `skills/*/SKILL.md`.
- C. Create `docs/product/PRD-v0.1.md`, `docs/product/backlog.md`, and `docs/architecture/adr/ADR-001-modular-monolith.md`.
- D. Create monorepo skeleton, Docker Compose, and CI.

Business functionality starts after Week 0 foundation review.
